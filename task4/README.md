Разминка

1. Чем комментарий // отличается от /* … */ и когда какой удобнее?
   // — это однострочный комментарий удобен для коротких пояснений к конкретной строке, а /* … */ — многострочный удобен для длинных описаний или временного отключения больших фрагментов кода.
2. Что напечатает инструкция std::cout << "5+3=" << 5 + 3 << std::endl;
   5+3=8 и переведёт курсор на новую строку.
3. Чем endl отличается от \n? Чем они похожи?
   Оба переносят вывод на новую строку, но std::endl дополнительно принудительно очищает сбрасывает буфер вывода, а \n просто вставляет символ переноса строки.
4. Назовите три вида ошибок и скажите, как каждая проявляется: до запуска, на сборке или после запуска.
   Синтаксические ошибки проявляются на этапе сборки компиляции, ошибки времени выполнения runtime — после запуска в виде аварийного завершения, а логические — после запуска в виде неверного результата работы.
5. Чему равно 7 / 2? Чему равно 7 % 2? Чему равно 125 % 60?
   7 / 2 равно 3, 7 % 2 равно 1, 125 % 60 равно 5.
6. Чем 7 / 2 отличается от 7.0 / 2? Почему?
   7 / 2 даёт 3 (целочисленное деление отбрасывает дробную часть), а 7.0 / 2 даёт 3.5, так как наличие дробного числа 7.0 переводит операцию в вещественное деление.
