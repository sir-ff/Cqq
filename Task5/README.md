## 1. Предсказание к заданию 2 (до запуска)
* **Было:** `2147483647` (максимальное значение для 32-битного `int`).
* **Стало:** `-2147483648` (произойдёт переполнение, число перейдёт в минимальное отрицательное).
* **Удвоенное:** `-2` (из-за переполнения при умножении максимального значения на 2).

## 4. Краткие выводы по заданиям
* **Задание 1 (`sizes.cpp`):** Тип `int` занимает 4 байта (32 бита), один бит выделен под знак, поэтому диапазон значений составляет от `-2 147 483 648` до `2 147 483 647`.
* **Задание 2 (`overflow.cpp`):** При превышении максимума происходит знаковое переполнение (смена знакового бита и переход в отрицательную область).
* **Задание 3 (`population.cpp`):** Для хранения значений порядка миллиардов необходимо использовать 64-битный целочисленный тип `long long`.
* **Задание 4 (`counter.cpp`):** Промежуточный результат вычисления миллисекунд за 20 лет (`630 720 000 000`) превышает диапазон `int`, поэтому первому множителю требуется суффикс `LL`.
