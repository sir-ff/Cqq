3.`temperature.cpp`
Тестовые данные: `36.6` °C и `97.88` °F.

Вывод программы:
```text
Цельсий: 36.6
Фаренгейт: 97.88
Фаренгейт: 97.88
Цельсий: 36.6
Испорченная прямая формула: 68.6
```

Сравнение прямой формулы до и после порчи масштаба для `36.6` °C:
До порчи `9.0 / 5.0` или `1.8`: `97.88` °F
После порчи `int scale = 9 / 5;`: `68.6` °F

Объяснение:
В выражении `9 / 5` оба операнда являются целыми числами (`int`), поэтому компилятор выполняет целочисленное деление и отбрасывает дробную часть (`1.8` превращается в `1`). В результате формула фактически превращается в $F = C \times 1 + 32$, и при подстановке `36.6` получается $36.6 + 32 = 68.6$ вместо правильных `97.88`. Чтобы деление было дробным, хотя бы одно из чисел должно быть вещественным (например, `9.0 / 5`).
